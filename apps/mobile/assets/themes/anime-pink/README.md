# Separate anime-pink originals

No hero/character artwork was supplied separately with the reference mockup. Missing files intentionally use the code gradient, not an extracted/generated image or folklore artwork.

Supply these original files when ready:

- `home/hero.png`
- `program/hero.png`
- `progress/hero.png`
- `profile/hero.png`
- `workout/hero.png`, `standard.png`, `emom.png`, `pyramid.png`
- Optional future exercise originals in `exercises/` (existing exercise art remains unchanged).

JPG originals are also supported. Register each provided file in `src/themes/anime-pink/assets.ts` with a literal `require('../../../assets/themes/anime-pink/home/hero.png')` (adjust the path per slot). Metro needs literal paths; never require an absent file. Hero/immersive images use `cover`; exercise characters use `contain`. `HomeHeroArtwork` and `ThemeArtwork` also accept an explicit React Native image source. No raster graphic is generated by this theme.
